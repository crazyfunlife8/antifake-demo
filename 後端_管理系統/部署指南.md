# 防偽驗證系統 — VPS 部署指南

---

## 打包 / 交付說明

壓縮包應包含 `後端_管理系統/` 資料夾，但需**排除**以下項目：

| 排除項目 | 原因 |
|---|---|
| `.env` | 含機密資訊，伺服器上需自行建立 |
| `venv/` | 伺服器上需重新安裝 |
| `staticfiles/` | 由 `collectstatic` 自動產生 |
| `__pycache__/`、`*.pyc` | 編譯快取，不需要 |

---

## 升級現有部署

```bash
# 1. 停止服務
sudo systemctl stop antifake

# 2. 解壓新版檔案，直接覆蓋整個專案目錄

# 3. 執行 migration（必跑）
source venv/bin/activate
python manage.py migrate

# 4. 重啟服務
sudo systemctl start antifake
```

> 本次新增 migration 0007（`geo_city` 欄位），`migrate` 為必要步驟，跳過會導致後台錯誤。

## Nginx 上傳大小設定（必做）

前台上傳照片功能需調整 Nginx 設定，否則會出現 HTTP 413 錯誤：

```nginx
server {
    client_max_body_size 20M;   # 加這行

    location / {
        proxy_pass http://127.0.0.1:8000;
        ...
    }
}
```

改完後重新載入 Nginx：

```bash
sudo nginx -t
sudo nginx -s reload
```

## 部署步驟

### 1. 建立虛擬環境並安裝套件

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. 建立 `.env` 設定檔

在 `manage.py` 同層目錄新增 `.env` 檔案，內容如下：

```env
# 必填：隨機安全金鑰，不可留空或使用預設值
SECRET_KEY=換成你自己的安全金鑰

# 生產環境必須設為 false
DEBUG=false

# VPS 的 domain 或 IP（多個以空格分隔）
ALLOWED_HOSTS=yourdomain.com 123.456.789.0

# 對應 https domain（防 CSRF 攻擊）
CSRF_TRUSTED_ORIGINS=https://yourdomain.com
```

> `SECRET_KEY` 生成方式：
> ```bash
> python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
> ```

### 3. 初始化資料庫

```bash
python manage.py migrate
```

### 4. 建立管理員帳號

```bash
python manage.py createsuperuser
```

依提示輸入帳號、Email、密碼。

### 5. 收集靜態檔案

```bash
python manage.py collectstatic --noinput
```

### 6. 啟動服務

```bash
gunicorn backend.wsgi --bind 0.0.0.0:8000
```

將 `8000` 換成要監聽的 port。

## 資料庫

預設使用 **SQLite**，資料存在 `db.sqlite3`，VPS 上直接可用，不需要額外安裝資料庫軟體。

## 後台登入

服務啟動後，開啟 `http://yourdomain.com:8000/admin/`，使用第 4 步建立的帳號登入。

進入後台後，請至「系統設定（System Configs）」將 `SITE_BASE_URL` 設為網站的完整網址，例如：

```
https://yourdomain.com
```

## Nginx 反向代理（建議）

如需掛在 80 / 443 port，使用 Nginx 做反向代理：

```nginx
server {
    listen 80;
    server_name yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

SSL 憑證建議使用 Certbot（Let's Encrypt）免費申請。

## 長期運行（建議）

使用 `systemd` 管理 gunicorn，避免 SSH 斷線後服務停掉。

新增 `/etc/systemd/system/antifake.service`：

```ini
[Unit]
Description=Antifake Gunicorn
After=network.target

[Service]
User=你的系統使用者
WorkingDirectory=/你的專案路徑/後端_管理系統
EnvironmentFile=/你的專案路徑/後端_管理系統/.env
ExecStart=/你的專案路徑/後端_管理系統/venv/bin/gunicorn backend.wsgi --bind 0.0.0.0:8000 --workers 2
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

啟動服務：

```bash
sudo systemctl daemon-reload
sudo systemctl enable antifake
sudo systemctl start antifake
```

## 目錄結構說明

```
後端_管理系統/
├── manage.py          # Django 管理指令入口
├── requirements.txt   # 套件清單
├── .env               # 環境變數（需自行建立，不含在壓縮包中）
├── backend/           # Django 設定（settings.py、urls.py）
├── antifake/          # 主要應用程式（models、views、admin）
└── project/           # 前台靜態頁面與素材
```
