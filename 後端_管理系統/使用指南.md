## 前台操作流程

### 正常驗證流程（防偽碼存在）

1. 進入首頁 `/`
2. 輸入測試防偽碼：**`TEST1234567890`**
3. 輸入驗證碼圖片上顯示的 4 位數字
4. 點「查詢」
5. 跳至 `/checkTruth.do`，顯示「本產品被拆封驗證第 N 次」結果
6. 點「下一步」進入問卷頁 `/Questionnaire.do`

### 無效碼流程（防偽碼不存在）

1. 進入首頁，輸入任意**不存在**的防偽碼（例如 `INVALID123`）
2. 跳至 `/checkTruth.do`，顯示「您查詢的防偽碼無法比對！」
3. 點「下一步」進入補件回報頁 `/genDetemItemForm.do`
4. 上傳照片並填寫聯絡資訊後送出
5. 顯示 lightbox 提示「請重新查詢正確的防偽碼，或與我們聯繫」

### 一、防偽碼管理（Anti Fake Codes）

#### 清單頁面

- 欄位：防偽碼、驗證次數、啟用中、最近驗證時間、備註、建立時間
- **預設只顯示「使用中（未刪除）」的防偽碼**
- 右側篩選器：
  - **刪除狀態**：使用中 / 已刪除（切換後可看到軟刪除的碼）
  - **啟用中（Is active）**：是 / 否
  - **驗證次數**：0 次（未驗證）/ 1 次 / 2–4 次 / 5 次以上（異常）
  - **建立時間**：按年/月/日鑽取
- 搜尋框：可依防偽碼或備註關鍵字搜尋

#### 新增單筆防偽碼

1. 點右上角「Add Anti Fake Code」
2. 填入「Code」（防偽碼字串，建立後不可修改）
3. 可填備註（Notes），勾選「Is active」（預設為勾選）
4. 點「Save」儲存

#### 批量新增防偽碼

路徑：右上角按鈕「批量新增防偽碼」或直接開啟  
`/admin/antifake/antifakecode/batch-create/`

兩種方式擇一：

**方式 A：CSV 匯入**
- 準備 CSV 檔，每行格式：`防偽碼,備註（備註可省略）`
- 範例：
  ```
  ABC12345678,批次A
  DEF98765432
  ```
- 選擇檔案後點「上傳並匯入」；已存在的碼會自動跳過（不覆蓋）

**方式 B：系統隨機產生**
- 填入「產生數量」（最多 10,000）、「碼長度」（預設 12 位）
- 可選填備註（批次標記用）
- 點「產生並建立」，系統使用排除易混淆字元（0/O/1/I）的字集自動生成不重複碼

#### 編輯防偽碼

- 點清單中任一筆 → 可修改「備註」、「Is active」
- 防偽碼本身（Code）在建立後為唯讀，無法更改
- 驗證次數、首次/最近驗證時間、建立/更新/刪除時間均為唯讀系統欄位

#### 軟刪除 / 還原 / 永久刪除

在清單頁勾選目標後，從「Action」下拉選單執行：

| 動作 | 說明 | 權限 |
|---|---|---|
| 軟刪除選取的防偽碼 | 標記刪除（仍保留資料，驗證時視為無效） | 所有管理員 |
| 還原已刪除的防偽碼 | 取消刪除標記，恢復有效 | 所有管理員 |
| ⚠️ 永久刪除（無法復原，僅限管理員） | 從資料庫實際刪除，不可復原 | 僅 superuser |

> 注意：右側「Delete」按鈕已停用，防止誤刪；請透過上述 Action 操作。

#### 匯出防偽碼

勾選目標後執行：
- **匯出選取項目為 CSV** — 下載 `.csv`（UTF-8 with BOM，Excel 可直接開啟）
- **匯出選取項目為 Excel** — 下載 `.xlsx`

匯出欄位：防偽碼、驗證次數、啟用中、首次驗證時間、最近驗證時間、備註、建立時間

> 匯出需要 superuser 或屬於「管理員」「法務」群組，否則顯示權限錯誤。

#### 查看單筆驗證歷史（Inline）

點開任一防偽碼 → 頁面下方「驗證歷史（時間倒序）」顯示該碼每次被驗證的紀錄：
- 驗證時間、當次次數快照、來源 IP、GPS 緯度/經度、User Agent

### 二、驗證歷史（Verification Logs）

- 每次有人在前台查詢防偽碼，系統自動寫入一筆記錄
- 此模組為**唯讀**（不可新增或修改）
- 欄位：防偽碼、驗證時間、當次次數、IP、緯度、經度
- 搜尋：可依防偽碼或 IP 搜尋
- 篩選：依驗證時間日期鑽取
- 可匯出 CSV / Excel（需有匯出權限）

#### 異常檢測報表

路徑：`/admin/antifake/verificationlog/anomaly/`  
（後台首頁或驗證歷史清單頁會有連結）

報表即時計算以下三類異常：

| 類型 | 條件 | 說明 |
|---|---|---|
| 同碼高頻查詢 | 同一防偽碼 24 小時內被驗證 ≥ 5 次 | 疑似重複掃碼或惡意驗證 |
| 同 IP 大量查詢 | 同一 IP 今日驗證 ≥ 10 個不同防偽碼 | 疑似批量掃碼攻擊 |
| 同 GPS 大量查詢 | 同一定位座標今日驗證 ≥ 10 個不同防偽碼 | 疑似同地點批量掃碼 |

---

### 三、上傳檔案（Uploaded Files）

- 記錄所有透過「補件回報（genDetemItemForm）」頁面上傳的照片
- 欄位：檔案編號（fileNo）、檔名、Content-Type、檔案大小、上傳時間
- 此模組為唯讀，可用來核對補件回報中的圖片

---

### 四、聯絡我們（Contact Tickets）

- 記錄前台「聯絡我們（contact.do）」頁面送出的表單
- 欄位：姓名、信箱、電話、防偽碼、問題類型、問題描述、購買日期、提交時間
- 篩選：問題類型、是否為會員
- 搜尋：姓名、信箱、防偽碼
- 可匯出 CSV / Excel（需有匯出權限）

匯出欄位：姓名、信箱、電話、防偽碼、問題類型（顯示名稱）、問題描述、購買日期、提交時間

---

### 五、補件回報（Supplement Reports）

- 記錄前台「補件回報（genDetemItemForm.do）」頁面送出的資料
- 欄位：聯絡資訊、上傳照片（fileNo 關聯至上傳檔案）、提交時間
- 可匯出 CSV / Excel（需有匯出權限）

匯出欄位：聯絡資訊、上傳照片 fileNo、提交時間

---

### 六、問卷回應（Questionnaire Responses）

- 記錄前台問卷頁（Questionnaire.do）填答的內容
- 欄位：防偽碼、提交時間
- 搜尋：防偽碼
- 可匯出 CSV / Excel（需有匯出權限）

匯出欄位：防偽碼、回答內容（JSON 格式）、提交時間

---

### 七、系統設定（System Configs）

- 控制系統行為的參數，**不可新增或刪除**，只能修改「Value」
- Key 欄位為唯讀，不可更改

| Key | 說明 | 範例值 |
|---|---|---|
| `VERIFY_WARN_THRESHOLD` | 驗證次數達此值時顯示警示訊息（紅字） | `2` |
| `SERVICE_PHONE` | 警示訊息內顯示的服務電話 | `0800-004-088` |
| `BLOCK_CONTENT_7` | checkTruth 頁頂部活動看板，可填入 HTML 字串 | `<a href="..."><img ...></a>` |

修改步驟：
1. 點選要修改的 Key
2. 修改「Value」欄位
3. 點「Save」

---

### 八、使用者管理（Users）

#### 新增員工帳號

1. 後台首頁 → Users → 右上角「Add User」
2. 填入使用者名稱與密碼
3. 點「Save」後進入權限設定頁
4. 勾選「Staff status」（必須勾選，才能登入後台）
5. 在「群組（Groups）」勾選對應群組

#### 群組與權限

| 群組名稱 | 具備匯出權限 | 說明 |
|---|---|---|
| 管理員 | ✅ 是 | 一般後台管理人員 |
| 法務 | ✅ 是 | 法務部門查閱匯出用 |
| （無群組） | ❌ 否 | 只能瀏覽，無法匯出 |
| superuser | ✅ 是（含永久刪除） | 最高權限，另可永久刪除防偽碼 |

> 說明：只有 superuser 或屬於「管理員」「法務」群組的帳號才能執行匯出 CSV / Excel 操作。

#### 停用帳號

進入使用者編輯頁 → 取消勾選「Active」→ Save  
被停用的帳號無法登入，資料仍保留。
